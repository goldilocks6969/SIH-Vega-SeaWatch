# SeaWatch UX North Star

> **“SeaWatch turns the ocean from a map you look at into a system you can ask.”**

## Experience goals

1. A first-time viewer should understand within approximately 10 seconds that the ocean is interactive.
2. Tapping the sea should feel natural and rewarding.
3. Agent collaboration should be visible without looking technical.
4. Marine intelligence should manifest geographically wherever possible.
5. Disaster conditions should be immediately understandable.
6. The user should never have to understand the underlying technical architecture.
7. Evidence and sources should be available on demand but not clutter the default screen.
8. The interface should remain useful even if every backend capability is simulated.

## Interaction model

Keep the default experience sparse and disclose information progressively: **tap → inspect → understand → go deeper**.
